# 🌌 Upgrading the AI Multiverse

An interactive AI chatbot built as part of the **MirAI School of Technology – AI Builder Virtual Summer Internship 2026**.

This application uses the **Google Gemini API** to create conversations with different AI personalities. Users can select a personality and control the intensity of the AI's responses.

## 🚀 Features

- 🤖 AI chatbot powered by Google Gemini
- 🎭 Multiple AI personalities
- 🎚️ Adjustable response intensity from 1–10
- 💬 Interactive user input
- ⚡ Real-time AI-generated responses
- 🔐 API key loaded securely using environment variables
- 🖥️ Simple and interactive Streamlit interface

## 🎭 Available Personalities

The application includes:

- 👨‍🏫 Helpful Teacher
- 👨‍💻 Expert Hacker
- 😂 Funny Friend
- 😰 Panicked College Student
- 🕴️ 1920s Mafia Boss
- 💪 Sarcastic Fitness Coach

Each personality changes the style and tone of the AI's response.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- `google-genai`
- `python-dotenv`
